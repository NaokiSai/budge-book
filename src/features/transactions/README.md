features/transactions（記録） の中に含まれるべきもの
「画面」ではなく「機能（ドメイン）」単位で考えるとき、Home画面や Add画面で使われている以下のパーツやロジックは、すべて transactions という1つのグループにまとめられます。

表示系（Home画面で使っているもの）

家計簿の明細リスト（BudgeList.tsx）

リストの1行1行（BudgeListItem.tsx）

フィルター機能（「今月のみ」「カテゴリ別」などの絞り込み）

入力・編集系（Add画面などで使っているもの）

金額、カテゴリ、支払方法、メモなどを入力するフォーム全体（DataFormFields.tsx など）

各種入力パーツ（FormAmount.tsx, FormCategory.tsx 等）

データ通信・状態管理（ロジック）

GASから「家計簿のデータ一覧」を取得するAPI呼び出し

新しい支出をサーバーに保存したり、削除・更新したりする処理（カスタムフック）
